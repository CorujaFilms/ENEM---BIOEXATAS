Física

Fórmulas Essenciais

  • Cinemática: v = Δs / Δt, s = s0 + v0 t + 1/2 a t²
  • Dinâmica: F = m · a, P = F · v
  • Termodinâmica: Q = m · c · Δθ
  • Eletromagnetismo: F = k · (q1 · q2) / r²
  • Óptica: n = c / v

Matemática

Fórmulas Essenciais

  • Função do 1º grau: y = ax + b
  • Função quadrática: y = ax² + bx + c
  • Área do triângulo: A = (b · h)/2
  • Área do círculo: A = π · r²
  • Probabilidade: P(E) = n(E)/n(S)
  • Estatística: Média: x̄ = Σx / n, Mediana e Moda
  • Matemática Financeira: Juros simples: J = C · i · t, Juros compostos: M = C · (1 + i)ⁿ
